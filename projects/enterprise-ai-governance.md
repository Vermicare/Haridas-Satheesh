# Enterprise AI, EPMO & Governance

## CORTEX
**Status:** Architecture / R&D

An EPMO-first governance intelligence architecture combining:
- meeting intelligence,
- governance memory,
- decision lineage,
- RAID intelligence,
- enterprise signals,
- AI agents,
- controlled execution,
- human validation.

The aim is to move governance from periodic manual reporting toward persistent, evidence-based intelligence.

---

## Governance Meeting Intelligence Layer
**Status:** Architecture / Prototype Design

Proposed pipeline:

**Teams transcript → minutes → decisions → actions → RAID → dependencies → human validation → structured memory → follow-up**

The problem being addressed is information loss between meetings, reporting and execution systems.

---

## Governance Memory Graph / Governance Memory Mesh
**Status:** Architecture

Persistent representation of:
- decisions,
- evidence,
- owners,
- risks,
- issues,
- dependencies,
- escalations,
- reversals,
- outcomes.

The purpose is organizational memory instead of treating each governance cycle as an isolated event.
